# AI 健康伴侣 · 文档中心

面向个人用户的 **AI + 健康管理应用**，聚焦 **饮食健康** 与 **睡眠健康** 两大场景。
产品理念：**"零焦虑、重陪伴"**。核心闭环：**无感采集 → 智能评估 → 最小可执行微行为 → 形成正循环**。
