# 「AI 健康伴侣」完整产品功能清单 (V1.2 整合版)

> 产品初衷与理念：现代人因高压工作常常忽略身体信号。科技的进步让我们有机会拥抱“百岁人生”，但前提是建立良好的身体底子。本产品旨在以“零焦虑、重陪伴”的方式，帮助年轻打工人重新学会感知身体信号，通过智能设备与 AI Agent 建立**“无感采集 ➔ 智能评估 ➔ 最小可执行微行为 ➔ 形成正循环”**的健康生活习惯。

## 一、 全局基础设施与多端无感互联 (Infrastructure & Device Sync)

* 1.1 极简登录与初始化



  * 一键授权登录：支持第三方（微信 / Apple / Google）或手机号快速登录。

  * 身体基础档案：首次登录采集身高、体重、年龄、性别、日常活动量及核心健康目标（如：抗疲劳、改善睡眠、控糖、增强精力）。

  * 设备与权限引导：一键引导授权相机权限、系统通知权限，以及 HealthKit / Health Connect 健康数据同步。

* 1.2 智能穿戴设备无感互联 (Wearable Integration)



  * 实时数据静默同步：静默读取智能手表/手环的睡眠时长、睡眠阶段（深睡/浅睡/REM）、心率变异性（HRV）、静息心率、久坐时长、站立次数、每日步数等。

  * 设备状态感知：感知手表佩戴状态，确保数据采集的准确性，并在离线时支持本地存储、联网后自动补全。

* 1.3 隐私与本地优先存储



  * 数据安全加密：健康敏感数据本地加密存储，符合数据安全及隐私保护规范。

  * 脱敏上传与随时撤回：支持用户随时导出健康报告或清除长期记忆档案。

## 二、 基于生理节律的全天候 Agent 陪伴闭环 (Daytime Rhythm Agent)

### 2.1 晨间唤醒与“防亏空”评估（07:00 - 07:30）

* 闹钟与睡眠质量分析报告：闹钟响后，Agent 根据昨晚手环睡眠/HRV 数据自动生成“身体电量与睡眠洞察”。

* 晨间唤醒 Routine：

  * 睡眠充沛（电量 > 80%）：推荐 3-5 分钟活力唤醒拉伸或觉醒冥想。

  * 睡眠亏空/熬夜（电量 < 50%）：Agent 自动触发“防亏空保护机制”，叫停剧烈运动安排，推送晨间舒缓冥想，并给出当日营养补偿策略（如：“今日建议早餐多补充优质蛋白，抗炎抗疲劳”）。

* 通勤健康卡片（科普与观念建立）：

  * 对接权威资讯（如中国营养学会），在通勤路上推送“每日健康海报/卡片”。

  * 主题覆盖：“为什么要多吃优质蛋白？”、“少吃油的骗局与优质脂肪的重要性”、“水是最好的代谢催化剂”等，强化健康观念。

### 2.2 早餐唤醒与“三要素”评估（07:30 - 08:30 - 重点强化）

* 拍照/语音早餐识别：拍早餐照片或语音输入（如“吃了两个鸡蛋、一杯牛奶和一根蒸玉米”），AI 自动进行“三大唤醒要素”诊断：

  * 优质蛋白质诊断：精准识别鸡蛋、牛奶/无糖酸奶/豆浆、瘦肉或豆制品。若缺少蛋白，提示：“早餐缺少优质蛋白，上午容易提早产生饥饿感和血糖波动。”

  * 优质碳水诊断：识别复合低 GI 碳水（番薯、蒸玉米、纯燕麦、全麦面包）vs 精制碳水（油条、白面包、含糖糕点）。

  * 膳食纤维/微量元素诊断：识别绿叶蔬菜、小番茄或低糖水果。

* 早餐缺口跨餐记账：若早餐缺乏蛋白质或纤维，Agent 自动将缺口计入当日营养账本，并在午餐打卡前主动提示：“早餐缺少蛋白质，中午建议优先选择鸡胸肉或牛肉补充。”

### 2.3 日间精力管理与微行动干预（09:00 - 12:00 / 14:00 - 18:00）

* 久坐与站立交替提醒：

  * 手环/手机监测连续久坐满 1 小时，Agent 发出柔性提醒：“已经坐很久啦，站起来活动一下吧！”

  * 推送 2-5 分钟办公室椅上拉伸、肩颈放松指导动画。

* 水动力提醒（喝水卡片）：

  * 根据用户体重计算每日饮水目标（如 2000ml）。

  * 智能检测饮水间隔，超时未打卡触发智能提醒：“你已经 2 小时没有喝水啦，补充一小杯温水唤醒脑细胞吧！”

* 注意力与生物钟匹配：结合用户生理数据（如 HRV 与高疲劳期），提醒用户在下午 3 点低谷期进行 3 分钟深呼吸或去倒水放松。

### 2.4 午间与晚餐后过渡（12:00 - 14:00）

* 饭后散步与血糖稳态提醒：

  * 午餐打卡结束后，自动弹出提示：“饭后散步 10-20 分钟，能显著平抑血糖波动，避免下午食余昏睡。”

* 午休充电方案选择：

  * 散步结束后，Agent 引导用户选择午间恢复模式：“30分钟小睡提醒” 或 “15分钟午休降压冥想”。

* 下午工作激励：午休结束后，Agent 发送温情鼓励语与唤醒提示，帮助快速回归高效工作状态。

### 2.5 晚间运动规划与睡前降噪（18:00 - 23:00）

* 运动日程与用餐时序规划：

  * 如果当日有运动安排（如网球、跑步、羽毛球），Agent 智能校准时间窗口（提示：“建议饭后 2 小时再运动，且晚餐不晚于晚 8 点，运动不晚于晚 10 点，避免交感神经兴奋影响睡眠”）。

  * 根据睡眠状况动态调整：若前一夜睡眠极差，Agent 自动建议将高强度运动替换为瑜伽、慢走或简单拉伸。

* 睡前无缝降噪（嵌入小宇宙播客）：

  * 睡前 30 分钟触发准备睡眠通知，一键调起小宇宙助眠播客/白噪音/睡前放松冥想，助打工人切换至副交感神经状态。

## 三、“七大要素”质感饮食档案 (Zero-Calorie-Anxiety Diet)

摒弃传统精算卡路里带来的焦虑，专注于“吃的质量”与“营养结构”。

### 3.1 拍照多模态识食与“七大要素”评估

* 多模态拍照打卡：拍外卖或餐盘，AI 识别菜品与食物种类。

* 文字/语音补充打卡：支持发语音“中午吃了一碗牛肉面加个蛋”解析为结构化数据。

* 七大营养要素结构化诊断：

  1. 早餐三要素（专项）：重点诊断“优质蛋白（鸡蛋/牛奶/豆浆）+ 优质碳水（番薯/玉米/燕麦）+ 膳食纤维”，确保上午供能稳定。

  2. 碳水化合物：评估是否为优质低 GI 碳水（粗粮/薯类 vs 精制碳水）。

  3. 蛋白质：评估是否易消化吸收（如白肉、豆制品、鸡蛋），提醒成人 (0.8-1.2g) × 体重(kg) 的基本缺口。

  4. 膳食纤维：评估绿叶菜/蔬菜占比（对照每日 25g/约 500g 蔬菜目标）。

  5. 脂肪质量：识别重油反复煎炸 vs 优质油脂（Omega-3/6/9，坚果、橄榄油等）。

  6. 水分摄入：关联全天饮水总量。

  7. 维生素与矿物质：评估新鲜蔬果的色彩丰富度，以及镁、锌、铁等关键微量元素的摄入。

* 热量模糊估算：仅提供区间参考（如：适中 / 偏高），不做强制数字扣减，重在指出改进方向。

### 3.2 营养缺口累积与跨餐建议

* 营养缺口数据条：实时展示“碳水、蛋白质、膳食纤维、优质脂肪、水分、维生素、矿物质”的当日达成进度。

* 下一餐智能推荐：如果早餐/午餐缺乏膳食纤维与蛋白质，晚餐打卡前 Agent 自动建议：“今天缺少绿叶菜和优质蛋白，今晚建议补充一份白灼青菜+清蒸鱼。”

### 3.3 饮食档案与“起居注”复盘

* 建立专属饮食档案库（类似健康病历簿），支持按日期复查历史每一餐的照片、营养评价与改善建议，直观感受自己的饮食变好过程。

## 四、 睡眠与运动健康管理 (Sleep & Motion)

### 4.1 睡眠健康度评估

* 睡眠结构图：自动解析深睡、浅睡、REM 快速眼动与清醒次数。

* 归因分析：关联晚间进食时间、运动强度、咖啡因摄入对深睡时长（如深睡 < 1小时）的影响。

### 4.2 运动计划与动态安全护栏

* 对接运动计划：支持输入每周运动想法（如每周 3 次跑步），Agent 评估其合理性。

* 防亏空降级机制：检测到连续高压、高心率、低睡眠时，强制将运动方案降级为“恢复性微行为”（如泡脚、拉伸、慢走）。

## 五、 数据档案与“身体起居注” (Living Archive)

### 5.1 每日“身体起居注”手帐卡片

* 每晚自动汇总今日数据（睡眠分、早餐完成度、七大要素覆盖率、冥想时长与次数、拉伸完成度、饮水量）。

* 生成日系手帐风/极简风的“身体起居注”图片，包含 Agent 温暖个性化的御医寄语，可一键保存或分享。

### 5.2 健康数据档案库

* 冥想与拉伸累计：记录累计冥想分钟数、拉伸次数、连续打卡天数（Streak）。

* 正向正循环勋章体系：达成“优质脂肪达人”、“早餐唤醒大师”、“深睡恢复大师”、“喝水达人”等成就勋章。

## 六、 多端智能通知与触达矩阵 (Notification Engine)

* 锁屏 Rich Notification：锁屏直接展示身体电量、下一餐营养补救卡片与拉伸入口。

* 穿戴设备震动提醒：手表端精简推送喝水提醒、久坐拉伸动作提示与睡前唤醒。

* 智能降噪与免打扰：设置静默时段（如 22:30-07:00），连续未响应的提醒自动降频，绝不给打工人制造骚扰。
