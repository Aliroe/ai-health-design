**【作品简介 · AI 健康伴侣】**

**① 项目名称**：AI 健康伴侣

**② 行业赛题**：AI 智能体应用设计赛道

**③ 目标用户**：高压工作人群、睡眠不佳者及控糖等慢病关注人群。

**④ 核心问题**：健康数据碎片化、记录摩擦大；市面产品止步"识别+图表"，**缺少能听懂口语化描述大部分用户停留在数据存储，没有统一数据的方案及行动建议、**并推动健康管理"最后一步"的个性化健康 Agent。
**⑤ 解决方案**：移动端 App，构建"无感采集→智能评估→微行为→正循环"闭环。健康管家、营养师、睡眠教练三类 Agent 协同：拍照识食、语音记录、七大要素质感诊断、跨餐补缺、身体电量与防亏空保护、节律陪伴与锁屏干预；每条建议落为可执行任务，反馈回流迭代。

**⑥ 创新点**：闭环型多 Agent 编排——不只"问答"，而是任务理解、流程编排、工具调用、多轮交互、结果交付五要素全闭环；以"模糊估算+七要素"零焦虑诊断替代卡路里焦虑。

**⑦ 开放/复用价值**：底层"知识库+Agent 编排+闭环状态机"架构可复用于心理咨询、母婴护理、慢病管理等垂直场景。

**⑧ 当前进展**：已完成 SRS/PRD、15 页高保真原型、多 Agent 工作流编排与食物成分数据源调研，正进行 Agent 工作流调试。
