    中国食物成分数据源调研¶

    配套需求：SRS FR-DIET-01/03/04（拍照识食、食物库检索、扫码录入）、FR-DIET-12（七大要素诊断）、KG 食物知识库 状态：调研完成 · 推荐优先方案见 §5 编写日期：2026-08-09

    1. 结论先行¶

    方案 数据来源 规模 获取方式 成本 适合阶段
    ① 开源 JSON（第6版） Sanotsu/china-food-composition-data 第6版"一般营养成分"全部条目（千余条） GitHub 克隆 免费 MVP 首选
    ② MCP/内置数据 ruffood/cn-food-mcp / free-fitness ~1725 种食物 × 25 营养素 GitHub / NPM 免费 MVP 备选
    ③ 官方查询平台 中国疾控中心营养与健康所 nlc.chinanutri.cn 全量 网页查询（无开放 API） 免费 数据校验基准
    ④ 官方开放数据 公共卫生科学数据中心 / 国家人口健康数据中心 2002 版 1506 条 × 31 项 申请下载 免费 科研/补充
    ⑤ 商业 API/库 唤醒食物 / 薄荷开放平台 / CnOpenData 1700~1800+ 种 商务对接 付费 V1.0 规模化
    ⑥ 国际对照 USDA FoodData Central 全量（SR 传统+品牌） REST API（免费 key） 免费 海外/进口食品补充

    项目 SRS 中"内置 ≥10 万条食物库"（FR-DIET-03）指含品牌食品的总条数；基础营养成分表以第6版权威数据打底（①），品牌食品量靠后续接入商业库（⑤）与用户修正回流补齐。行业调研结论一致："初期用 AI 估算 + 常见 10 万条 + 用户修正回流"。

    2. 官方权威数据源（基准）¶

    2.1 《中国食物成分表》标准版第 6 版（2019）¶

    • 主编单位：中国疾病预防控制中心营养与健康所（杨月欣主编），中国营养学会
    • 结构：3 个分册
    • 第一册 植物性食物：1110 余条一般营养成分 + 修订胡萝卜素/VA/碘/GI 值 + 250 余条脂肪酸 + 870 条胆碱等植物化学物
    • 第二册 动物性食物与食品：8 大类 3600 余条食物（其中 1005 条一般营养成分，数据 75600 余个），宏量营养素 10 种 + 维生素 11 种 + 矿物质 10 种 + 氨基酸 20 种 + 脂肪酸 45 种 + 490 种食物嘌呤数据
    • 第三册 加工食品
    • 用途：国内一切营养计算的权威基准；本项目"食物知识库 KG"的底层数据
    • 获取：纸质/PDF 购买（无公开电子档）；查询平台见 §2.2

    2.2 食物营养成分查询平台（官方在线查询）¶

    • 网址：https://nlc.chinanutri.cn/fq/
    • 运营：中国疾病预防控制中心营养与健康所 + 中国营养学会
    • 能力：按食物分类/名称检索营养成分、营养标签查询
    • 限制：网页查询，无开放 API——适合作为数据校验基准与运营后台人工查证，不适合产品直连

    2.3 中国食物成分数据库（政府开放数据）¶

    • 公共卫生科学数据中心：https://www.phsciencedata.cn/Share/ky_sjml.jsp?id=577e0301-ab65-432a-9bb7-a8342302e589
    • 国家人口健康科学数据中心：https://www.ncmi.cn/phda/dataDetails.do?id=CSTR:A0006.11.A0006.201906.000293
    • 内容：基于 2002 年食物成分表的 1506 条食物 × 31 项营养成分（含胆固醇）+ 氨基酸 657 条 × 18 种 + 脂肪酸 441 条 × 32 种 + 碘 130 条 + 大豆异黄酮 114 条，总计约 5 万条记录
    • 限制：目前"暂不共享实体数据，元数据可公开获取"——需正式申请

    2.4 其他官方/学术¶

    • 中国营养学会资料：https://www.chinanutri.cn/（历版食物成分表、DRIs 膳食参考摄入量）
    • 浙江大学膳食营养大数据平台：https://nutrition.zju.edu.cn/（科研平台）

    3. 开源可落地数据（MVP 直接可用）¶

    3.1 Sanotsu/china-food-composition-data ⭐推荐¶

    • 仓库：https://github.com/Sanotsu/china-food-composition-data（231 stars）
    • 内容：第 6 版"能量和食物一般营养成分"部分的完整表格数据，已由 OCR / 通义千问 2.5-VL 视觉模型转为 JSON
    • 字段（每 100g 可食部）：
    • 能量页：foodCode、foodName、edible(可食部%)、water、energyKCal、energyKJ、protein、fat、CHO(碳水)、dietaryFiber、cholesterol、ash、vitaminA、carotene、retinol、thiamin(VB1)、riboflavin(VB2)
    • 营养素页：niacin(烟酸)、vitaminC、vitaminETotal/1/2/3、Ca、P、K、Na、Mg、Fe、Zn、Se、Cu、Mn、remark
    • 组织方式：按食物类别合并的 JSON 文件（如 merged-禽肉类及其制品-鸡.json），含"代表值"条目
    • 注意：作者已移除"婴幼儿食品"数据（奶粉品牌数据非通用）；数据经 OCR/视觉模型转写，入库前需抽样人工校对
    • 样本示例（鸡-代表值）：能量 145 kcal / 蛋白 20.3g / 脂肪 6.7g / 碳水 0.9g / 膳食纤维 0.0g / 胆固醇 106mg / Ca 13mg / Fe 1.8mg / Zn 1.46mg / Se 11.92μg

    3.2 ruffood/cn-food-mcp（MCP Server）¶

    • 仓库：https://github.com/ruffood/cn-food-mcp
    • 内容：~1725 种中国食物 × 25 种营养素（每 100g），TypeScript 实现
    • 能力：search_food 搜索 / get_nutrition 完整营养 / compare_foods 对比 / filter_by_nutrient 按营养素筛选
    • 价值：可直接对接本项目的"营养师 Agent 工具层"（Function Calling / MCP 协议），也可作为数据结构参考；含食物 ID 便于外键关联

    3.3 Sanotsu/free-fitness（内置数据参考）¶

    • 仓库：https://github.com/sanotsu/free-fitness
    • 内容：开源健身 App，内置第 6 版食物成分数据 + 单份营养素换算（如"100g=200kcal"、"1 只=300kcal"）
    • 价值：可参考其份量模型（同一食物多单份）与本地存储设计

    4. 商业数据源（V1.0 规模化）¶

    来源 规模/能力 获取 备注
    唤醒食物 API https://www.foodwake.cn/api/introduce 1780 种食物 × 54 种营养素（每 100g）+ 类黄酮 360 种 + 不饱和脂肪酸 7090 种；提供 MySQL SQL 文件 商务购买终身使用权 数据最全的国内商业库；可按"有效诉求"做营养推荐
    薄荷健康开放平台 https://open.boohee.com/ 食物营养数据平台，含品牌包装食品库 注册申请 品牌食品（条码扫码）首选；支持 FR-DIET-04 扫码录入
    CnOpenData 中国食物营养成分数据 https://www.cnopendata.com/data/m/food%26medical/nutrition.html 超 1700 种 × 含量表+得分表 商业购买 含营养成分得分，便于"好/坏"评分展示
    USDA FoodData Central API https://fdc.nal.usda.gov/api-guide SR Legacy + Foundation + 品牌食品 + FNDDS；公开领域 CC0 REST API 免费 key 进口食品/海外用户补充；免费

    5. 落地建议（对接本项目）¶

    阶段 数据动作 对应需求
    MVP 克隆 ① 开源 JSON → 清洗校对 → 导入食物库表（FoodRecord 的 foodId 关联）；营养字段与"七大要素"对齐（蛋白/碳水/纤维/脂肪质量/水分/维生素矿物质） FR-DIET-01/12
    MVP 并行 以官方查询平台（§2.2）为基准抽样校验开源数据准确率 SRS §10.1 验收（识别 ≥90%）
    Beta 接入 ② cn-food-mcp 作为营养师 Agent 工具（MCP/Function Calling） FR-AGENT-02 工具调用
    V1.0 申请 ⑤ 薄荷开放平台 → 补品牌食品库（扫码）；评估唤醒食物做营养评分推荐 FR-DIET-04/07
    长期 用户修正回流（份量/菜品修正样本）扩充"常见食物"库；海外版接 USDA API 行业调研"用户修正回流"

    注意事项 - 版权：第 6 版表格数据为出版物内容，仅可用于产品内部功能数据，不建议原样对外分发；USDA 为 CC0 公开领域 - 合规：健康数据类 App 引用营养数据需在隐私政策与免责声明中注明数据来源与"估算值"性质（SRS §6.3） - 校验：开源数据经 OCR/视觉模型转写，存在错行/错位风险，入库必须过一轮字段级校验（能量 kJ/kcal 换算一致性、可食部范围、营养缺失值 Tr/— 处理）
