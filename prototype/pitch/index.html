高压打工人的日常

熬夜、外卖、久坐、睡眠不足——体检报告逐年多几个箭头，生活节奏却一点没变。

90% 健康产品止步"识别 + 展示"

拍照记卡路里、给你看图表——告诉你"缺蛋白"，没人帮你"吃对"。用户三分钟热情，然后流失。

💡 我们的判断：健康管理缺的不是"知道"，而是"做到"——从"建议"到"执行"的最后一公里，是行业普遍缺失的空档。

02 · 用户痛点

数据碎片、记录摩擦、建议落地难

🧩
看不全

饮食、睡眠、运动数据分散在不同设备，无法关联归因。

✍️
记不住

手动记录卡路里繁琐反人性，大部分用户坚持不过 3 天。

🤔
听不懂

结论是"蛋白占比 12%"，而非"午餐选鸡胸肉还是牛肉"。

🚫
做不到

建议停留文字，无提醒、无任务、无反馈，更不会越用越懂你。

⚠️ 一句话：健康数据有记录、无闭环——"最后一步"（执行与反馈），是整个行业的断点。我们的所有设计，都在补这个断点。

03 · 产品形态与核心流程

从"拍一张照片"到"养成一个习惯"

移动端 App ｜ 两步上手：首次建档 → 一键授权 ｜ 五步闭环，全程 ≤10 秒可见
STEP 1📸 3 秒记录

拍照识食 / 一句话语音"一碗牛肉面加个蛋"→ 自动结构化

STEP 2🧠 智能分析

能量环 + 七大要素诊断（蛋白/碳水/纤维/脂肪/水分/维生素），缺项给"为什么"

STEP 3📋 可执行任务

早餐缺蛋白 → 生成"午餐补鸡胸肉/牛肉"任务，缺口入账本

STEP 4🔔 主动干预

锁屏推送"还差 320 kcal，推荐清蒸鲈鱼+糙米饭"，一键直达

STEP 5🔄 反馈回流

完成/忽略/纠正回流 Agent 记忆，次日建议自动变准

⏰ 另有全天候陪伴：晨间身体电量 → 通勤健康卡 → 久坐拉伸 → 午休方案 → 睡前降噪，按生理节律主动触达。

04 · Agent 能力

三位健康顾问，协同完成一次健康干预

🏠
健康管家 Agent · 编排者听懂意图 · 决定找谁 · 何时提醒 · 冲突仲裁

跨域调度（咖啡因 ↔ 深睡归因）；冲突仲裁——"昨晚睡眠差，今天还能跑步吗？"由它裁决并透明说明原因。

🔧 任务编排🔧 通知文案🔧 记忆维护
🥗
营养师 Agent · 领域专家解析记录 · 七要素诊断 · 跨餐补缺

调用食物库 + 营养计算引擎，输出人话点评与可执行补缺任务。

🔧 食物库检索🔧 营养引擎🔧 七要素规则
😴
睡眠教练 Agent · 领域专家结构分析 · 归因 · 防亏空保护

深睡/REM/HRV 归因找因；身体电量 <50% 触发防亏空硬约束（模型无权越过）。

🔧 穿戴数据🔧 运动护栏
✅ Agent 判定五要素：任务理解 · 流程编排 · 工具调用 · 多轮交互 · 结果交付——不是多段 Prompt 串联，而是真正闭环的多 Agent 协作。
示例：熬夜后电量 42% → 跑步自动降级为慢走 → 早餐补蛋白 → 午餐前提醒补绿叶菜 → 全程透明说明。

06 · 合规边界

健康无小事，AI 有底线

🏥
非医疗定位

所有输出均为健康生活方式建议，明确"不构成医疗诊断"，免责声明贯穿全链路。

🛡️
风险护栏

极端饮食/厌食倾向/疾病提问自动引导就医；防亏空等安全规则为确定性硬约束。

🔒
数据最小化

本地优先，原始照片与明细默认不上云；输入脱敏，不用于训练第三方模型。

✋
用户主权

授权可撤回、记忆可查看删除、注销 30 天彻底清除、数据可导出。

💬 合规对标：《个人信息保护法》《数据安全法》《生成式人工智能服务管理暂行办法》，等保二级起步。AI 陪伴有温度，合规底线有硬度。

07 · 后续落地计划

三步走：从闭环到生态

第一阶段 · MVP → Beta（公测）

账号 + 拍照/语音记录 + 能量分析与七要素基础诊断 + Agent 闭环（任务/锁屏通知/反馈回流）——验证"记录→干预→反馈"核心价值。

第二阶段 · V1.0（商业化）

七大要素完整诊断、起居注、跨餐记账、能量报告；上线 AI 深度版/家庭共享版订阅；接入体检机构 API 与社区卫生服务中心。

第三阶段 · 生态扩展

小米/华为/三星手环绑定与穿戴通知；开放"知识库+Agent 编排"底层架构，向心理咨询、母婴护理、慢病管理垂直场景复用。

🔁 商业：免费基础版 + 订阅增值 ｜ 数据飞轮：用户修正样本回流训练——越用越准、越用越懂，闭环本身就是壁垒。
